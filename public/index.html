Process

How it works

Three steps from nothing to a published game.

  1. Sign in — email + code, GitHub, or continue as a guest to look around. Saving, publishing, and coins need an account.
  2. Build in Studio — write by hand, import files, or import a Scratch project. Press Run and the preview is the real thing.
  3. Publish — set a title, description, and thumbnail. Your game goes live in the gallery with its own page.

About

About Cudic

Cudic is a place to hang out and a place to build. It combines a chat and community layer with a full browser-based game studio, a gallery of playable games, theme packs that restyle the whole site, and a small currency for rewarding the people who make things. Everything runs in the browser, so there is nothing to install, nothing to build, and nothing to host. You open a tab and start.

The studio is a real workbench, not a toy. It has a file explorer, editor tabs, a live preview that assembles your files into a working page, and a command palette for every action. You can write HTML, CSS, and JavaScript by hand, import existing files or whole folders, or bring a Scratch project across and keep editing it. Python runs in the browser through WebAssembly, and npm packages resolve from a public CDN, so the same code that works in the preview works in the published game.

Games publish to a shared gallery with permanent pages, card art, comments, likes, and remix. A game you publish can be forked by anyone, with credit carried up the chain forever. Progress saves follow the player's account across sessions and devices, and multiplayer rooms let people play together in real time without extra downloads or accounts at other services. Guests can play along, and signed-in players appear with their account name, which the server sets so nobody can fake it.

FAQ

Frequently asked

Q

Do I need to install anything?

No. Cudic runs entirely in the browser. Open the site, sign in or continue as a guest, and start building or playing.

Q

Is it free?

Yes. There is no paid tier and no subscription. Coins are earned, not bought, and theme packs are priced in coins.

Q

Can I use my own code?

Yes. Import files or folders, write by hand, or paste. Local CSS and JS siblings are inlined automatically, and projects export as a zip.

Q

What about Scratch games?

Import a .sb3 file or a shared Scratch link. The project comes across as editable data, runnable as-is, with costumes and sounds as normal files.

Q

How do saves work?

Signed-in players get cloud saves bound to their account. Games opt in, and the game frame never holds a login token, so saves stay sandboxed.

Q

Can people play together?

Yes. Published games can open live rooms over Cudic's connection. Up to 32 players per room, small messages, and guests join without an account.

Q

What are theme packs?

Full site restyles: colours, fonts, rail icons, background art, motion, and a live scene. Try any pack instantly; buying with coins keeps it.

Q

Are coins real money?

No. Coins are Cudic's own currency for theme packs. They cannot be bought with money or cashed out; you earn them.
