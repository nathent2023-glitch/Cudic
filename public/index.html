// three things, one tab

Everything you need to go from a blank file to a playable link.

Build in Studio

A full workbench in the browser tab — file explorer, editor, live preview and console, side by side. No local server, no setup.

Publish to the gallery

One click gives your game a page, a link and comments. Take any published game, fork it, and start from someone else's code.

Chat while you play

Spin up a lobby, drop the link in a call, and keep the history if you want it. Servers with membership are there when you need them.

// the editor

A real workbench, in a browser tab.

Open a project and you get the thing you already know: a file tree, a tabbed editor, a running preview and a console that tells you what broke.

  • Plain files. HTML, CSS and JavaScript — export it and it still works anywhere.
  • Preview beside the code. Save and the running page updates next to what you typed.
  • Publish in one move. Set a thumbnail, hit publish, and it lands in the gallery.
