Construction

The Cudic “C” is a single solid shape: two rounded arms joined by a notched spine. Use it only as supplied, in one flat color. Never outline, stretch, rotate or add effects.

Clear space & size

Keep clear space equal to the width of one arm on every side. Minimum size 16px for the mark, 80px for the wordmark. Wordmark is Geist Medium, tracking −3%.

Cursor pack

10 cursors · 32px · hover to try

A symmetrical pixel cursor set drawn on a 16-cell grid and shipped at 2× (32×32). Cream with an ink edge reads on any background, and a lime spark marks the hotspot. Choose Pixel for blocky or Fluid for smooth: the same ten cursors in two styles.

hover a tile to try · click to copy CSS
Construction
  • Shapes sit on a 14-cell grid with a 1-cell edge, then ship at 2×.
  • Every mirrored cursor is built from one quarter, so both sides are exactly equal.
  • Cream fill, ink edge, one lime spark. Link uses blue.
  • Fluid style: smooth vector strokes on a 32-unit canvas with round caps and joins, a cream core inside an ink edge.
Usage
html { cursor: url("default.svg") 1 1, auto; }
a, button { cursor: url("link.svg") 1 1, pointer; }
input { cursor: url("text.svg") 8 14, text; }

Always add the keyword fallback after the image.

Rules
  • Square corners, 1px hairlines. No rounded pills, no shadows, no lift.
  • Buttons are mono caps with an arrow. Hover flips the fill to Cream and the arrow steps 4px.
  • Tiles are flat: a color block, text, and a footer bar. Hover swaps block color and inverts the footer.
  • Navigation: Gallery, Themes, Docs, Chat, Studio, with Sign in at the far right.

Motion

move in pixel steps

Motion moves in pixel steps. It is short, purposeful and always optional.

Hop

600ms · steps(2) · loop

Blink

1s · steps(2) · loop

Slide

2s · steps(8) · alternate

Timing
  • Fast 120ms: hovers and presses.
  • Base 240ms: icons and logos.
  • Slow 480–800ms: reveals and hero entrances.
Rules
  • Use steps() easing so motion lands on pixel boundaries. Smooth easing only for the ticker.
  • Buttons never lift or glow: the fill flips and the arrow steps 4px.
  • Honor reduced-motion: everything stops, content stays.

Guidelines

logo misuse

Quick rules for keeping the mark and layouts consistent.

don’t stretch
don’t rotate
don’t outline
don’t add effects
Do
  • Use the mark in one flat color: Cream, Ink, Lime or Blue.
  • Pair it with Geist Medium for the wordmark.
  • Place it on solid blocks or the Ink canvas.
Layout
  • Build on a hairline grid. Cells, not cards with shadows.
  • One hero color block per screen.
  • Max two pixel icons per cell.
Accessibility
  • Ink on Lime and Blue passes AA for text.
  • Never put Mute text on a colored block.
  • Icons never carry meaning alone. Add a label.
