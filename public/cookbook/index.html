Cudic Cookbook

Real guides for building real games

The Cookbook is a set of hands-on tutorials for making browser games in Cudic Studio. Every guide runs in the browser with no installs, and every code sample is a complete working page you can paste straight into Studio and run.

Guides · updated as the platform grows · questions live in the forums

Build a platformer

A complete jump-and-collect game in one pasteable page — game loop, gravity, collision, coins, and where to take it next.

Clicker game mechanics

Why idle games hook people, and how to build one: click value, upgrade costs, and the cost curve that keeps players coming back.

Cloud saves with CudicSave

Make progress follow the player across sessions — one script tag, a load and a save call. Covers guests, sign-ins and the 100 KB budget.

Multiplayer with CudicMulti

Put other people in the same room as your game: join, broadcast, and wire a simple two-player chase. Guest players need no account.

Canvas art tricks

Gradients, glow, particles and the device-pixel-ratio fix — the small techniques that make a game look like someone cared.

New here?

  1. Sign in (or continue as a guest) and open Studio — a full editor with a live preview.
  2. Pick a guide, paste the code, press Run in the preview bar.
  3. Publish when it feels good — the game appears in the gallery at /games.

Cookbook guides use the same APIs published games use, so everything you build here ships as-is. When you get something working, post it in the Showcase — it's the fastest way to get feedback.
