Cudic home

Cudic is a free browser studio for making small games. You write HTML, CSS and JavaScript (or import a Scratch project), preview it live in the same tab, and publish with one click. Published games get a page, a link, a playable embed, cloud saves, and multiplayer rooms — no installs, no setup, no build step.

What is Cudic?

A browser studio for small games: an editor with a file tree and live preview, a one-click publish pipeline, a gallery community, and built-in multiplayer, saves and chat. The whole loop — write, run, publish, share, talk — happens in one tab.

How much does Cudic cost?

Cudic is free to use. Advertising keeps it free; there are no paid tiers or limits on publishing.

Do I need to install anything?

No. The studio, the live preview and the player all run in your browser. Nothing to download, nothing to configure, no build step to learn.

Can I import my Scratch project?

Yes. Upload an .sb3 file or paste a Scratch project link. Cudic converts it into a real, editable HTML5 project — sprites, sounds, scripts and the running player — so you can then edit files and publish it. Scratch blocks are preserved and run as-is; they are not translated into hand-written JavaScript.

What can I build with?

Plain HTML, CSS and JavaScript files, including multi-file ES modules and npm packages that run in the browser. Python files also run through a browser-based Python runtime. There is no server-side execution, so Node built-ins and native binaries are not available.

Do players need an account to play my game?

No. Anyone with the link or the embed can play right away, with saves kept locally. An account carries progress across devices and adds cloud saves and chat.

Can I put my game on my own site?

Yes. Every published game comes with copy-paste iframe snippets — a fixed size and a responsive one. Embedded games keep local saves and work without a sign-in wall.

Does Cudic support multiplayer?

Yes. Published games can join shared realtime rooms of up to 32 players using a small built-in client API — join a room, send and receive messages. Rooms are anonymous and open to guests.

Can other people remix my game?

Yes. Anyone can fork a published game into their own Studio project. The fork keeps an automatic system credit on its page naming your game and the original maker, and the chain stays intact across further remixes.

How do I publish a game?

One click — Publish in Studio. Your project gets a gallery page with a thumbnail and comments, a shareable link, and embed snippets you can paste anywhere.
